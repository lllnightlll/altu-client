Неизвестный отправитель. Входящее до QR кладётся с нулевым ключом, в пузыре сырой ciphertext. Нужно: не показывать мусор, подпись вроде «scan QR to decrypt», после скана те же сообщения сами расшифруются — ключ уже подтянется из Room.
Статус исходящих. Очередь есть, в UI нет: pending / sent / failed. deliveredAt == null у своих сообщений как раз это значит.
Превью в списке чатов. Сейчас только ник и время, текст последнего сообщения не показывается.
Аватар контакта. У всех sound_icon. В QR аватара нет, на сервере тоже. Варианты: локально выбрать фото контакту или класть путь/миниатюру в QR.
Notifications. Тумблер ничего не делает: нет разрешения, канала и показа при новом inbox.
Профиль. Аватар только при регистрации, потом не сменить. Тег на сервере тоже не обновить — такого API нет.
Повторная регистрация с тем же тегом даст 409 — сервер пользователя не удаляет. Имеет смысл явно сказать «tag taken».
